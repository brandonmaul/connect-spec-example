# Sources

Where the content in this repo came from. New rules cite their source in the pull
request that adds them.

- **Nitro Connect Context Guide** (Jessy Barnes, last reviewed 2026-10-28): the
  UX-maintained guide this repo absorbed. Its terminology, design, behavior,
  projects and open questions now live here.
- **Nitro Connect Glossary** (2026-09-30): UI and device terminology with labeled screenshots.
- **connect-context-summary.md**: v2/v3 systems, the Bridge, CCL, and the v2 sunset project.
- **Team specs** (added 2026-10-14): Alphabetical and sorting rules, Keyboard Shortcut Recommendations, Markdown Support Proposal.
- **[PowerLife Connect articles](https://nitro.powerhrg.com/powerlife/headlines/tag_search?tag=Connect)** (18, Aug 2025–Sep 2026): user-facing behavior and release dates.
- **[Huddle: Nitro Connect collection](https://huddle.powerapp.cloud/project_collections/14)** (31 projects): handoff notes plus the Message Guide, Error Messaging Guide, Notification Routing Rules, and Terminology Guide specs. Figma embeds not reviewed.
- **Connect product context packet** (teammate, 2026-10-28): QA catalogs for Apple (CA-, 464 cases), Web/PWA (CW-, 258), Server (CS-, 44), and recent ticket records.
